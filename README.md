# Gestión de Productos

Aplicación web con inicio de sesión y gestión de productos.

- **Backend:** .NET 10 (ASP.NET Core Web API)
- **Frontend:** React 19
- **Base de datos:** SQL Server

## Estructura

```
backend/    API en .NET 10
frontend/   Aplicación en React 19
database/   Script de creación de la base de datos
```
